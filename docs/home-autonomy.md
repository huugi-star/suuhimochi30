# ホームの自発行動

- 部屋・個体・端末の描画準備が整えば開始する。外部情報の準備完了・取得成功を開始条件にしない。
- 初回の出会い、共有設定、部屋の案内、睡眠、会話、入力、日誌などの操作中は発動しない。これらが終わって自由操作に戻ったところから、初回は3,000〜5,000msを抽選する。初回案内のタップでこの短い待機を失わない。
- 初回はキャッシュから使える外部情報を試し、なければDAY会話への誘い、興味ズームの順に切り替える。未知のニュースは生成しない。学習語0件でも利用できる部屋の興味文とローカルの予備セリフがある。
- 2回目以降は、演出終了とカメラ復帰の完了後に5,000〜15,000msを毎回抽選する。起動後だけの固定シーケンスは使わない。
- タイマーは `components/useHomeAutonomy.ts` の単発タイマー1本。`lib/homeAutonomy.ts` が期限と演出履歴を管理する。再描画で期限を延長せず、同じ期限は一度しか発火しない。
- 別画面、非表示、手動操作では待機予定を破棄し、復帰後に改めて待つ。未実行の演出を蓄積しない。
- DAY会話への誘い、外部情報ズーム、興味ズーム、通常ひとり言、ダンスを抽選する。直近の種類を避け、直近5件の偏りを下げる。ズームなしの演出が2回続けば、次はズームを優先するため、2〜3回に1回ほどズームが入る。内容は直近8件を参照し、短い候補集も直近2件を避けて循環できる。
- 誘いを表示しただけではDAY会話を開始しない。「うん、聞かせて！」で既存台本を開始する。手動の「はなす」は待機時間の対象外。
- 外部情報のズーム会話が終わると、10,000〜15,000ms後にSELF台本への誘い、その会話が終わるとさらに10,000〜15,000ms後にCURIOUS台本への誘いを順番に行う。対応する未読台本がない場合はその誘いを飛ばす。誘いを断っても台本は消化しない。
- 外部情報は既存の最大8秒の準備タイムアウトとキャッシュを使って裏で取得する。`managed: true` のため、外部情報専用の自動発話タイマーは動かさず、共通タイマーが発話を選ぶ。取得中でもローカル会話は止まらない。
- 古い約17.5秒のひとり言タイマーは使用しない。歩行、睡眠、情報取得のタイマーとは役割を分ける。
- 誘い・ダンス・興味ズームでは学習、経験値、友好度を付与しない。

検証: `npm run test:home-autonomy`、`npm run test:home-autonomy:browser`、TypeScript型チェック。

ブラウザテストは実際のゲームコンポーネントをViteで描画し、ブラウザの保存領域をテストごとに分離する。初日・学習語0件で、外部情報0件・通信失敗・通信が止まった状態を検証する。部屋の案内を閉じてから4秒前後に最初のズーム、終了後の繰り返し、誘いの非消費、日誌・非表示・手動DAY会話への非割り込みを確認する。

スクリーンショット: `outputs/verification/home-autonomy-offline/`。Vercelへのデプロイや本番実機での確認はこのローカル検証には含まない。
