# ホームの自発行動

- `lib/homeAutonomy.ts` が、演出の終了とカメラ復帰の完了後に15,000〜30,000msを毎回抽選する。タイマーは `components/useHomeAutonomy.ts` の単発タイマー1本。
- 起動の最初の機会は外部情報を優先。外部取得は部屋を止めず、正常キャッシュを先に使う。初回準備は既存の最大8秒タイムアウトで終了し、候補なしは別の演出へ代替する。
- 起動演出が終了した15秒後に通常のひとり言、その終了15秒後に興味・疑問のズーム発言。その後はランダムな待機。
- 手動操作、別画面、非表示状態では予定を破棄する。復帰後に新しい待機を開始し、未実行演出をキューへ蓄積しない。ユーザー操作が入った場合は起動の残りの演出も再生しない。
- 演出はDAY会話への誘い、外部情報ズーム、興味ズーム、通常ひとり言、既存ダンス。直近8件の内容と直近5件の種類を参照する。
- DAY会話への誘いでは候補の有無だけ確認する。「お話しする」で初めて既存の台本を開始する。手動の「はなす」は待機時間の対象外。
- 旧17.5秒の発話タイマーと4.5秒の初回ひとり言タイマーを撤去。歩行、睡眠、情報取得のタイマーは発話スケジュールから独立。
- 外部情報の手動・定期更新は取得とキャッシュ更新だけを行い、発話は共通の待機サイクルで選ぶ。発話のための追加通信は行わない。
- 通常ひとり言と興味ズームは既存 `dialogueData.ts` のセリフを利用。誘い・ダンス・興味ズームで学習、経験値、友好度を付与しない。

検証: `npm run test:home-autonomy`、`npm run test:home-autonomy:browser`。
ブラウザ検証では既存のPlaywright/Chromeを環境変数で指定できる。通常のブラウザ保存とは分離したテスト保存を使う。
