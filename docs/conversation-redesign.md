# すうひもち会話の整理メモ

この版では、会話機能を次の3ファイルへまとめています。

- lib/conversationData.ts: 表示文、カテゴリー、選択肢
- lib/conversationTypes.ts: 会話・記憶・保存データの型
- lib/wordMemory.ts: セッション進行、記憶、30日目標、localStorage

キャラクターの独り言は lib/dialogueData.ts、画面表示は components/SuuhimochiGame.tsx に残し、会話ロジックと表示データを混ぜない構成です。以前の lib/conversation/* を参照するコードは残していません。

## 目的

『どこでもいっしょ』の公開情報から確認できる核は、ポケピにコトバを教え、そのコトバが後の会話で使われることです。PlayStation公式はシリーズを「ポケピにコトバを教えながら、おしゃべりを楽しむ、お話しゲーム」と説明しています。

開発者インタビューでも、教えたコトバを後から使うレスポンス、プレイヤーを知りたいから質問すること、キャラクターを「自分の友達」として置くことが語られています。

- [PlayStation公式](https://www.playstation.com/ja-jp/games/dokodemoissyo/)
- [GAME Watch 開発者インタビュー](https://game.watch.impress.co.jp/docs/interview/1208814.html)
- [4Gamer 開発者インタビュー](https://www.4gamer.net/games/000/G000000/20120517082/index_2.html)

公開資料から初代の内部辞書や質問重み、全文法を復元できるわけではありません。この実装は、公開された体験の核をAPI・LLMなしで小さく再現する独自実装です。

## 現在の会話フロー

1. 初回だけ、30日後に見たい景色をユーザー自身の文章で受け取る。
2. 通常会話では、新しいコトバ・気分・過去のコトバの再会話から一つを選ぶ。
3. 新しいコトバは、入力欄で一語を受け取り、種類を選び、好き・気になる・ふつうを選ぶ。
4. 再会話では、覚えたコトバを「覚えてる」「最近も見る？」の形で呼び戻す。
5. 20会話ごと、または数日ごとに30日目標の進み具合を尋ねる。
6. 30日目は目標と覚えたコトバを手紙にまとめる。

選択肢を使うのは、自由文の解釈を無理に装わず、記憶へ入れる情報の意味を明確にするためです。選択肢中でも submit と choose の両方を受け付け、UI更新の瞬間的なずれでは会話を切らないようにしています。

## 保存

保存キーは suuhimochi_conversation_v6_choices です。単語、種類、感情、再会話、目標、目標チェック、会話ログ、30日目の手紙に必要な値を端末内へ保存します。

- 会話終了後も同日中に再開できる
- 既に覚えたコトバは再び未知語として聞かない
- 目標や単語を端末外へ送信しない
- 保存に失敗しても会話そのものは止めない

## テスト

npm run test:conversation では、次を検証します。

- 初回目標の保存
- コトバの種類・気持ち・記憶
- 同日複数会話
- 過去のコトバの再会話
- 目標チェックと次の行動
- 30日目の別れと手紙
- 保存後の再読み込み
- 表示された台詞と会話ログの一致

自由文の映画批評や複雑な否定文を解析する旧テストは、現在の選択肢設計と目的が違うため削除しました。これは機能を隠すためではなく、実際の現行フローをテストするためです。

npx tsc --noEmit --incremental false、npm run lint、npm run build も通過させます。
