# 起動・情報更新時の外部情報ひとり言

## 実装

再読み込み・起動時は既存のズーム会話UIを利用し、外部話題を1件表示する。専用のスキップボタンで部屋に戻れる。手動更新時は従来の `.thought-bubble` を再利用する。外部情報はどちらもクリック進行とし、自動ページ送り・自動消去を行わない。SELF6・LEARN6のセッションを作らず、経験値・友好度・単語学習・日誌の更新も行わない。既存の通常会話・コンボ終了時の外部情報との接続は変更しない。

- 起動：部屋を表示してから非同期に取得。Day1は既存の出会い・興味取得・コンボ導線を優先する。
- 手動更新：開発者モニターの既存「今すぐ再取得」の開始イベントを利用し、各情報源の取得完了を1つの機会にまとめる。モニターを閉じるまでは話さない。
- 更新確認：従来どおり1時間間隔と表示復帰時（前回から1時間以上）。
- 表示：設定・日誌・軍師・六占・会話・コンボ・卒業・睡眠・共有知識の初回選択などを避け、最後の操作から2.5秒以上のアイドル状態で1件だけ。操作中・モーダル中は表示機会の期限を停止し、閉じた後に再判定する。アイドル時の候補なしは最大2分で終了する。
- 起動や表示は通信を待たない。各通信にタイムアウトを設け、共有辞書のページ送りが長くかかっても発話候補の収集は最大8秒で区切る。
- 起動会話の準備中だけ通常の自発ひとり言を控え、通常ひとり言との表示競合を防ぐ。部屋の操作や移動は停止しない。表示直前に競合した場合も同じイベントを再試行する。
- 開発者モードの「外部話題 → 自発会話の表示診断」で、取得中・待機理由・候補なし・表示済みと会話エンジンの日数を確認できる。診断の保存は通常会話・日誌・報酬を変更しない。

## 取得と選択

アプリの `/api/external-briefs` が固定の公開 `/safe-briefs` を読み、Gemmaの完成セリフを原文のまま取り込む。`trend_context` を含む現行形式を受け付け、先頭240件の一括制限を情報源別上限に変更した。アプリからAI生成は呼ばない。

既存 `/api/external-topics` のGoogle・Wikipedia・YouTube、完全一致・同意確認済みの共有知識、設定済み都道府県の天気を合わせる。共有辞書は既存の日次キャッシュと検証を維持し、起動・更新では許可済みの一致語（最大5語）の完成セリフだけを更新する。天気は既存の47都道府県設定・代表区域・原文を利用する。

照合は既存エンジンの既知語・コンボ派生語・明確な別名・根拠付きカテゴリー関連を再利用し、訂正された関係は再採用しない。関係のある候補を優先し、一般の公開話題もすうひもち自身の関心として選ぶ。完成済みGemma文がない場合に限り、従来の事実を付け足さない発見文を利用する。天気は受信文がない場合に創作文で補わない。

古いフィード・公開停止・不正URL・危険な文を除外する。「今日」「明日」を含む完成文は生成日が日本時間の当日であることも確認する。取得失敗では正常かつ有効なキャッシュを保持し、成功した0件・公開停止は古い文を復活させない。

## 重複と保存

起動ID・更新要求IDを一度だけ処理し、同時取得をまとめる。短時間の更新は30秒の発話クールダウンを設ける。個体別に話題ID・原文・情報源・日時・発動理由を端末保存し、同じ話題や同じセリフの連続使用、24時間以内の再利用を抑制する。情報源の利用頻度を考慮し、2回連続した情報源以外の候補があれば切り替える。

表示して初めて履歴を保存する。外部トレンドと共有知識の利用履歴は既存エンジンでも記録し、モニターと通常会話から参照できる。共有知識の出典は既存の出典表示を再利用し、Wikipediaへ別画面で移動できる。個体別IDで履歴を分け、30日後の次の個体の出現制限に混ぜない。外部へ日誌・プロフィール・回答文章・個体の記憶を送信しない。

## 変更ファイル

- `app/api/external-briefs/route.ts`：公開説明カードの固定プロキシ。
- `lib/externalBriefs.ts`：現行形式・情報源別上限・完成文の原文保持。
- `lib/externalBriefClient.ts`：取得・正常キャッシュ・公開停止の処理。
- `lib/externalMonologues.ts`：候補・公平性・履歴・一回性・保留。
- `components/useExternalMonologues.ts`：起動・手動更新・アイドル時の発話制御。
- `components/SuuhimochiGame.tsx`：既存のひとり言表示との接続と旧自動ズーム経路の置換。
- `components/ExternalTopicMonitor.tsx`：自発会話の待機・表示結果の診断。
- `lib/externalInfoClient.ts`：既存の取得イベントに発動元を追加。
- `lib/sharedKnowledgeClient.ts`：許可済み一致語のセリフ更新オプション。
- `lib/wordMemory.ts`：会話枠や学習を増やさない実発話履歴。
- `lib/externalTopics.ts`：完成文の改行・長さを保持する履歴復元。
- `scripts/fixtures/external-monologues.mjs`、`scripts/test-external-monologues.mjs`、`scripts/test-external-monologues-browser.mjs`：検証。
- `package.json`：検証コマンド。
