# 外部情報と学習済み単語の誤検出修正

## 原因

`lib/externalTopics.ts` のタイトル照合は、日本語を正規化した後に `haystack.includes(needle)` を実行していた。このため「まり」が「集まりました」の一部として一致し、`exact` として会話テンプレートへ渡されていた。英字の旧判定も空白を削除してから最初の出現だけを調べていた。

別経路の `lib/externalBriefs.ts` にも `title.includes(w)` による候補の加点があった。中カテゴリーの根拠も「歌」「曲」等の部分正規表現だったため、同じ方針で境界を確認するよう揃えた。

## 最小限の修正

- 新しい共通モジュール `lib/externalWordMatch.ts` で、端末内の `Intl.Segmenter('ja', { granularity: 'word' })` を使用する。
- 語の境界で区切られた完全な候補だけを比較し、文字の部分一致は使用しない。複合固有名・フレーズは連続した単語区間全体で照合する。
- カタカナ・漢字・英数字の同じ種類の文字が直結した複合語の一部を除外する。空白を消して別の語を連結しない。
- ICUの分割は品詞・意味の確定ではない。例えば「まりも」が「まり／も」と分割されても、短いひらがな語や1文字の根拠は、全文一致・引用等による明示的な区切り・構造化された関連語の完全一致がない限り採用しない。
- 大・中カテゴリーだけで意味を決めず、既存の中カテゴリー候補も単語境界を満たす具体的な根拠を必要とする。明確な既存の別名・読み・コンボ派生関係は維持する。
- 分割機能がないブラウザでは、全文または記号・空白で明確に区切られた語だけを採用する。部分一致へ戻さない。
- 分割・候補集合は公開タイトルごとに最大512件キャッシュし、辞書の単語ごとに同じタイトルを再解析しない。AI・辞書API・外部通信は追加しない。
- 開発者プレビューも現在の照合結果を使用し、過去の誤一致を新たな根拠として流用しない。過去の会話記録そのものは書き換えない。

これは意味を完全に自動理解する機能ではなく、確認できる語境界・明示的な関連語・既知の別名による保守的な照合である。判断が曖昧な場合は、関連する記憶なしの一般話題として扱う。

## 原文・既存機能の保護

情報センターから受信した有効なGemma完成セリフは、関連する単語がなくても原文のまま使用する。完成セリフがない場合のみ既存の一般話題用の反応を利用し、「教えてもらったまり」等を補わない。

SELF・LEARNの会話枠、単語辞書・ことばコンボの登録仕様、記憶・報酬・保存形式、吹き出し・クリック進行・出典リンク、Cloudflare Workerは変更していない。

## 変更ファイル

- `lib/externalWordMatch.ts`：共通の語境界・曖昧性チェック。
- `lib/externalTopics.ts`：タイトル・関連語・中カテゴリー根拠の照合を共通化。
- `lib/externalBriefs.ts`：旧カード選択の部分一致加点を廃止。
- `lib/wordMemory.ts`：プレビューで現在の照合結果を再確認。
- `scripts/test-external-word-match.mjs`：誤検出・正検出・原文保持・保存不変・旧履歴・分割機能なしの再発防止テスト。
- `scripts/test-external-monologues-browser.mjs`：実際に「まり」を教えた状態で、問題のYouTubeタイトルを表示する検証。実時間の夜間は睡眠を妨げない既存仕様に合わせて検証する。
- `package.json`：`npm run test:external-word-match` を追加。

## 確認内容

「まり／集まりました」「まり／まりも」「マリ／マリオ」「マイ／マインクラフト」「AI／Thai」「音楽の根拠としての歌／歌舞伎町・曲／曲がった」などを拒否する。単独の「まり」・引用された「まり」、マインクラフトの正式名・明確な別名・コンボ派生語、明示的な関連語は認識する。

誤一致時のGemma原文保持、一般話題への切り替え、学習済み単語・記憶関係・12会話枠が変化しないことを比較する。過去の誤一致を含む履歴の復元と、現在のプレビューの非流用も検証する。

2026-10-23の結果：新規9件・既存302件・ブラウザ13フローすべて成功。TypeScript型チェック・対象モジュールlint・本番ビルド成功。ブラウザでは実際の学習処理で「まり」を登録した隔離データを使い、問題のタイトルでも一般話題として原文を表示し、単語との関係が登録されないことを確認した。夜間の実APIフローでは、外部会話で睡眠に割り込まない既存の制御を確認した。実行環境で200タイトル×100語の2万回の照合を計測した例は約64ms（環境により変動）。
