# 天気予報の連携

設定の「天気予報の都道府県」で47都道府県から1つ選ぶと、その場で端末に保存します。次回起動時から同じ都道府県を利用します。区域・市区町村・観測地点の選択はありません。部屋の右上の「天気予報」から今日・明日の予報を開けます。「選択しない」で利用を停止できます。

## 接続と保存

- 既存の情報センター `https://suuhimochi-info-hub.huugishiki.workers.dev` を利用します。Worker・D1・Cronは変更していません。
- アプリの `/api/weather?resource=regions` が `/weather-regions` を読み、`areaLevel: "prefectures"` と47件の `areas` を確認します。58地方の旧一覧は採用しません。
- 端末からの予報取得は `/api/weather?resource=forecast&pref=130000` の形式です。選んだ都道府県コード以外に区域・観測地点の入力を送りません。公開応答の `prefecture`・`representativeArea`・`area`・`days`・`precipitationPeriods`・`temperaturePoints`・`dialogue.text` を読みます。
- **公開APIの互換指定**：2026-10-22の実測では `/weather?pref=130000`、`pref=東京都`、`pref=016000` がすべて既定の大阪府を返しました。`office` にも同じ都道府県コードを渡すと、正しい都道府県の代表区域が返ります。アプリサーバーだけで `/weather?pref=130000&office=130000` と同じコードを併記します。追加の地域選択や `/weather-areas` の利用は行いません。
- 応答の都道府県コードが選択値と違う場合、または `representativeArea: true` がない場合は表示・保存しません。正しいキャッシュを保持し、取得できなかった旨を表示します。
- 旧設定のoffice・area・stationは、都道府県だけを残す形で移行します。北海道の各地方は016000、奄美を含む鹿児島県は460100、沖縄県の各地方は471000へまとめます。旧区域のキャッシュは代表区域の予報として流用せず、改めて取得します。旧ひとり言履歴は都道府県単位へ読み替え、同じ文章の再生を抑制します。
- 地域設定、予報キャッシュ、天気のひとり言の重複防止はそれぞれ専用の端末保存キーを使います。既存セーブ・単語辞書・日誌・個体記憶の構造を変更しません。
- 取得はバックグラウンドです。起動時は正常なキャッシュを先に利用し、通常は1時間間隔で再取得します。既存の外部情報更新、画面復帰チェック、開発者モードの再取得にも接続しました。
- 同時取得をまとめ、失敗後は5分間再試行を抑制します。通信タイムアウトはアプリサーバー4.5秒、端末6秒です。失敗時は正常なキャッシュを保持し、画面には取得できなかったことを表示します。
- 地域を変更している間に以前の地域の通信が完了しても、新しい地域の表示やキャッシュを上書きしません。

## 予報の表示

天気・数値・時刻は情報センターの値を表示します。最高・最低気温が未提供の場合は「未提供」と表示し、時刻別気温から最高・最低を作りません。降水確率は時間帯ごとに表示し、日全体の確率に変換しません。出典「気象庁」のリンクと発表時刻も表示します。設定と予報パネルの両方に「都道府県内の代表区域の予報であり、都道府県全域の天気ではない」ことを明示します。気温の地点も情報センターが指定した地点名を表示するだけで、追加選択は不要です。

予報の「今日・明日」は日本時間の午前0時を基準にします。ゲームの午前7時の活動日とは役割が違うため、活動日の定義は変更しません。保存した予報を再表示する場合も、日付で今日・明日を選び直し、古いデータにはその旨を明示します。現在の日付を含まない予報や36時間を超える予報は利用しません。

## 天気のひとり言

情報センターが返す `dialogue.text` を加工せず、既存の部屋のひとり言表示に渡します。起動後や予報更新後、通常のひとり言のタイミングで利用します。通信完了を契機に強制ズームは行いません。

初回の共有知識選択、会話・ことばコンボ・設定・日誌・軍師・六占・天気パネル・卒業・睡眠などの最中は、自動のひとり言を開始しません。同じ地域の同じ文章は1日に1回まで、異なる文章でも1時間以上間隔を空けます。古い予報や前日を「今日」と呼ぶ文章は話しません。SELF6＋LEARN6、単語学習、仮面経験値、友好度、日誌の保存処理には入りません。

## 今回の47都道府県化で変更したファイル

- `lib/weather.ts`：都道府県だけの保存、旧設定・履歴の移行、47件の一覧と代表予報の検証。
- `lib/weatherClient.ts`：都道府県コードだけで予報を取得。
- `lib/weatherServer.ts`：公開APIの互換指定、旧区域取得APIの廃止。
- `components/WeatherForecast.tsx`：プルダウン1つの即時保存、代表区域の説明、出典「気象庁」の表示。
- `components/SuuhimochiGame.tsx`：未選択時の天気ボタンのラベル。
- `scripts/test-weather.mjs`・`scripts/test-weather-browser.mjs`・`scripts/fixtures/weather-prefectures.mjs`：47都道府県、旧設定移行、代表区域と取得の検証。
- `docs/weather-integration.md`：利用方法、互換指定と確認結果の記録。

既存の取得間隔・タイムアウト・キャッシュ・情報更新・会話への組み込みを利用します。会話や報酬の処理、Cloudflare側のコードを変更していません。
