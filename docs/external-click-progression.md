# 外部情報のクリック進行・吹き出し追従

## 変更

- 起動時ズーム・更新時ひとり言の両方で、外部情報だけ自動消去と自動ページ送りを停止。
- 既存のページ分割を再利用し、長い原文は42文字以内の読みやすいページに分割する。内容・事実の書き換えは行わない。
- 既存の文字表示演出を維持。文字表示中のクリックは全文表示、表示完了後のクリックは次ページへ進み、最後は部屋に戻る。
- 吹き出しに「▼ クリックして進む」を表示。320ms未満の連打と二重クリックの2クリック目を抑止する。
- 起動時の画面全体をクリックすると即スキップする処理を解除。専用スキップボタンとEscapeは維持する。
- 会話表示中の新しい外部情報は既存の待機処理で保留し、現在のページを置き換えない。
- 既存の吹き出しと元ネタ表示を、ズームの影響を受けないゲーム内のレイヤーへ移す。描画済みのキャラクター・部屋・UIの矩形から左右配置を決め、しっぽの先端を顔付近へ向ける。画面余白と出典行の高さを確保する。
- 元ネタは別タブで開く。リンク操作ではページ送り・終了・移動を行わない。

通常のSELF・LEARN・通常ひとり言のタイマー、移動・表情・会話演出、取得API、保存・報酬処理、Cloudflare Workerは変更しない。

- `components/useExternalMonologues.ts`：表示中の会話への割り込み抑止。
- `components/ExternalSourceCaption.tsx`・`.module.css`：既存吹き出しの位置追従、しっぽ、クリック範囲、連打防止。
- `lib/externalBubbleLayout.ts`：画面内の左右配置・UI回避・顔へのしっぽ位置計算。
- `scripts/test-external-source-citation.mjs`：左右・画面端・PC・スマートフォンの配置検証を追加。
- `scripts/test-external-monologues-browser.mjs`：表示保持・複数ページ・最後のクリック・二重クリック・情報更新中の保持・元ネタの非進行・カメラ復帰を追加。
- `docs/external-monologues.md`：現在の進行方式に更新。
